🏷️ Rental Code Verification Test

API Endpoint Information

URL: http://127.0.0.1:8000/api/verify-rental-code

Method: POST

Authentication: Bearer Token Required

Content-Type: application/json

Get this from your login response or browser dev tools

📋 Usage Instructions

  1. Log in to your account via the regular API login endpoint
  2. Copy your Bearer token from the login response
  3. Paste the token in the "Bearer Token" field above
  4. Enter a valid rental code (format: RC123456)
  5. Click "Verify Rental Code" to test the verification

🔧 Expected Responses

  • Success (200): Returns complete rental history data
  • Not Found (404): Invalid rental code
  • Conflict (409): Code already linked to another user
  • Validation Error (422): Invalid code format
  • Unauthorized (401): Invalid or missing token
