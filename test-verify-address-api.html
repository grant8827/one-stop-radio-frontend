Test Verify Address API

1. Create Address Verification Request

2. Get User Addresses

3. Verify Address (Admin)

Available API Endpoints:

  • GET /api/verify-addresses - Get user's addresses
  • POST /api/verify-addresses - Create address verification request
  • GET /api/verify-addresses/{id} - Get specific address
  • PUT /api/verify-addresses/{id} - Update address (if pending)
  • DELETE /api/verify-addresses/{id} - Delete address
  • PATCH /api/verify-addresses/{id}/verify - Verify address (admin)
  • PATCH /api/verify-addresses/{id}/reject - Reject address (admin)
  • GET /api/verify-addresses-active-leases - Get addresses with active leases
  • GET /api/verify-addresses-expired-leases - Get addresses with expired leases
  • GET /api/verify-addresses-future-leases - Get addresses with future leases
